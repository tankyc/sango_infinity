## Phase 1.5 — 与旧演出体系的隔离（**2026-09-26 新增，已完成**）

### 起因

从编辑器日志里抓到退出 Play 模式时的真实报错：

```
Cannot set the parent of the GameObject 'window_dialog4' while its new parent 'UIRoot' is being destroyed
Some objects were not cleaned up when closing the scene. The following scene GameObjects were found: window_dialog4
```

**完整调用栈**（从日志抓的，不是推测）：

```
退出 Play 模式 → EditorSceneManager::RestoreSceneBackups → DestroyWorldObjects
  → UIDialog.OnDestroy()                    (UIDialog.cs:144)
    → GameDialog.OnWindowClosed()           (GameDialog.cs:265 的 finally)
      → GameDialog.TryAdvance()             (GameDialog.cs:190)
        → Window.Open → Window.CreateWindow (Window.cs:262)
          → Transform.SetParent(UIRoot)     💥
```

根因：`TryAdvance()` 在**场景销毁过程中**还从队列里取待播对话去开新窗口。
`GameDialog.Reset()`（会清队列）只挂在 `ScenarioLifecycle.BeginShutdown()`，**退出 Play 模式不走那里**。

调研详情见 `Data/测试剧情运作机制说明.md`。要点：

| | 旧体系 | 新体系 |
| --- | --- | --- |
| 名字 | `RenderEvent` | `Game/Event/` |
| 逻辑 | **硬编码在 C#** | **数据驱动**（JSON） |
| 代表 | `CityPersonSearchingEvent`、`PersonRecruit` | `EventDefinition` + `EventRunner` |

二者**共用同一个 `GameDialog` 对话队列**、共用**同一个 `GameSystem` 系统栈**，
并且**旧体系会在自己的演出中途抛 hook 去触发新体系**。

### 时间范围机制（2026-09-26 整理）

三套语义不同的机制，已写进 `Data/测试剧情运作机制说明.md` §3.4：

| 层 | 配置 | 比的是 |
| --- | --- | --- |
| ① 时间索引 | `Trigger.EarliestYear` / `LatestYear` | 游戏**当前**年份 |
