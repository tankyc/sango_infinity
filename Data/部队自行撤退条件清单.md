# 部队自行撤退条件清单

> 按"决策来源"分组。所有概率 / 阈值均可在 `AIConfig` 中调整（`Data/Common/AIConfig.json`）。

---

## 一、`Troop.AIPrepare()` — 每回合决策中枢

**前置**：`非玩家控制` 且 `非运输队`（运输队由 `TroopSupplyTroop` 单独处理）。
**执行顺序即优先级**，命中即 `return`。

> 注：曾有的"被攻击重创 → 逃离"分支已按需求移除。部队被攻击不再触发主动撤离，
> 只保留"状态不佳求援"与"断粮 / 兵少 / 士气低返城"两类。

### 1️⃣ 状态不佳 → 求援（脱离战线，非撤退）

| 项 | 条件 |
|---|---|
| 兵力 | `troops × 100 < MaxTroops × askSupplyHealthPercent`（默认 **30%**） |
| **或** 粮草 | `IsWithOutFood() == 1`（粮草 < 4 回合消耗） |
| 附近补给队 | `askSupplySearchRange`（默认 **12** 格）内存在**己方运输队**且其仍有物资 |
| 任务排除 | ∉ `TroopAskSupply` / `TroopReturnCity` / `TroopMovetoCity` |
| **去向** | `TroopAskSupply`（并把原任务存入 `missionParams1/2`，补满后**恢复**） |

### 2️⃣ 保存实力 → 就近返城 【基础撤退】

**前置**：当前任务 ∉ `TroopReturnCity` / `TroopMovetoCity`。
三个条件**各自独立**，任一满足即可能触发（各带独立概率）：

| 条件 | 判定 | 概率配置 | 默认 |
|---|---|---|---|
| **断粮** | `IsWithOutFood() == 1` | `retreatOutOfFoodChance` | **80%** |
| **兵力过低** | `troops < retreatMinTroops`（默认 **300**）<br>**或** `troops × 100 < MaxTroops × retreatTroopPercent`（默认 **25%**） | `retreatFewTroopsChance` | **60%** |
| **士气崩溃** | `morale ≤ retreatMinMorale`（默认 **10**） | `retreatLowMoraleChance` | **50%** |

**去向**：`TroopMovetoCity` → **最近的己方据点**（不是归属城，避免老家太远时半路覆灭）

## 二、`TroopSupplyTroop.DoAI()` — 补给队 / 运输队

**执行顺序即优先级**。

### 1️⃣ 我方大劣 → 拔腿就跑

`IsForceLosing`：**我方总兵力占比 < `supplyRetreatForcePercent`（默认 35%）**

```
myPower × 100 < (myPower + enemyPower) × percent
```
（`myPower` = 我方全部存活部队兵力之和；`enemyPower` = 与我方为敌的全部存活部队兵力之和）

→ 返回最近己方据点

### 2️⃣ 资源不足 → 返回补充

满足**任一**即返回（`supplyReturn*` 为 0 时该项不生效）：

| 资源 | 阈值配置 | 默认 |
|---|---|---|
| 兵力 | `supplyReturnTroops` | **3000** |
| 粮草 | `supplyReturnFood` | **6000** |
| 兵装 | `supplyReturnItems` | **100** |

**或**完全耗尽：`food ≤ 0` / `troops ≤ 0`

→ 返回最近己方据点

### 3️⃣ 离敌人过近 → 后撤

`IsTooCloseToEnemy`：与最近敌军距离 `< supplySafeDistance`（默认 **3** 格，约一个回合行程）

→ 向**最近己方据点**移动（不切换任务，仅本回合后撤）

### 4️⃣ 无补给对象 → 返回

`FindSupplyTarget` 在 `supplySearchRange`（默认 20 格）内找不到需要补给的友军

→ 返回最近己方据点

## 三、任务完成 / 目标失效导致的自动返城

各任务类在 `Prepare` / `IsMissionComplete` 中改写任务（**不是主动撤退，属于任务收尾**）：

| 任务 | 触发条件 | 去向 |
|---|---|---|
| `TroopOccupyCity` | 目标城为 `null` | `TroopReturnCity`（归属城） |
| `TroopOccupyCity` | 目标城**已被友军占领** | `TroopProtectCity`（该城，协防） |
| `TroopOccupyCity` | 目标城已是己方 | `TroopMovetoCity`（该城，即进城） |
| `TroopProtectCity` | 城内**已无敌人存活** | `TroopReturnCity` |
| `TroopProtectCity` | **归属城兵力 < 2000** 且目标是归属城 | `TroopReturnCity` |
| `TroopProtectCity` | 目标城**已被敌方占领** | `TroopOccupyCity`（死战，不撤） |
| `TroopProtectCity` | `priorityActionData == null` 且无最近敌人 | `TroopReturnCity` |
| `TroopDestroyTroop` | 目标部队阵亡 / 已非敌方 | `TroopReturnCity` |
| `TroopDestroyBuilding` | 目标建筑被毁 / 已非敌方 | `TroopReturnCity` |
| `TroopTransformGoodsToCity` | 目标城已非友军 | `TroopReturnCity` |
| `TroopMovetoCity` | 目标城已非友军 | `TroopReturnCity` |
| `TroopMovetoCell` | 已到达 / 目标丢失 | `TroopReturnCity` |
| `TroopBuildBuilding` | 建造完成 / 无法建造 | 归属城是友方 → `TroopReturnCity`；否则 → `TroopOccupyCity` |
| `TroopMovetoBuild` | 同上 | 同上 |
| `TroopReturnCity` | 目标 ≠ 归属城 / 非友军 | 目标为敌 → `TroopOccupyCity`；否则 → **纠正**为 `TroopReturnCity`（归属城） |
| `TroopAskSupply` | 已恢复到安全线 / 目标失效 | **恢复原任务**（不返城） |

> `TroopAskSupply` 的"恢复判定"：`IsRecovered` = **粮草不告急** 且 **兵力 ≥ 满编 × `askSupplyHealthPercent`（30%）**

## 四、兜底逻辑

**`Troop.TroopMissionBehaviour` getter**：

```csharp
if (missionType == 0 && mBelongCity != null && !IsPlayerControl)
    SetMission(MissionType.TroopReturnCity, mBelongCity.Id);
```

任务被清空（`missionType == 0`）的**非玩家**部队，会被自动指派为"返回归属城"。
（这也是此前"求援完成后丢失进攻任务"的根因，现已在 `TroopAskSupply` 中通过恢复原任务规避）

## 五、玩家部队

| 项 | 说明 |
|---|---|
| `AIPrepare` | `IsPlayerControl` 时**直接 return**，以上 1~3 全部不生效 |
| 任务完成 | 走 `ClearMission()`（回到玩家控制）而非自动返城 |
| 唯一例外 | `TroopSupplyTroop` 的返回逻辑对玩家补给队同样生效（属任务行为，非 `AIPrepare`） |

## 六、速查表（按阈值配置汇总）

| 配置项 | 默认 | 作用 |
|---|---|---|
| `askSupplyHealthPercent` | 30 | 触发求援 / 判定恢复的兵力门槛（%） |
| `askSupplySearchRange` | 12 | 搜索补给队范围（格） |
| `retreatOutOfFoodChance` | 80 | 断粮撤退概率（%） |
| `retreatFewTroopsChance` | 60 | 兵力过低撤退概率（%） |
| `retreatLowMoraleChance` | 50 | 士气崩溃撤退概率（%） |
| `retreatMinTroops` | 300 | 兵力过低绝对阈值 |
| `retreatTroopPercent` | 25 | 兵力过低相对阈值（满编 %） |
| `retreatMinMorale` | 10 | 士气崩溃阈值 |
| `supplyRetreatForcePercent` | 35 | 补给队"大劣"判定（我方兵力占比 %） |
| `supplyReturnTroops` | 3000 | 补给队兵力返回线 |
| `supplyReturnFood` | 6000 | 补给队粮草返回线 |
| `supplyReturnItems` | 100 | 补给队兵装返回线 |
| `supplySafeDistance` | 3 | 补给队与敌安全距离（格） |
