# 道具图标目录

本目录存放**全部道具**的图标（兵装 / 器械 / 船 / 宝物 / 装备），
由 `GameRenderHelper.LoadItemIcon(icon)` 加载、`UIItemType.SetIcon` 用 RawImage 展示。

## 目录位置

与头像（`Assets/Face`）、事件 CG（`Assets/CriticalImage`）一致：**Assets 下的顶层目录**，
不带 `UI/` 层级，Mod 可以用同样的相对路径整体覆盖，不必改代码。

| 位置 | 用途 |
|---|---|
| `Project/Assets/Mods/Content/Assets/ItemIcon/`（本目录） | 进 `Content` 资源包，**编辑器下由 AssetDatabase 直接命中**；发布包走 `Content.pkg` |
| `<ContentRootPath>/Content/Assets/ItemIcon/`（如 `Build/Content/Assets/ItemIcon/`） | 裸文件，开发期热改不用重新打包 |

## 命名规范

1. **文件名 = 道具 Id**（`ItemTypes.json` 里的 `Id`），扩展名**统一 `.jpg`**；
2. 数据侧只写 Id，不写扩展名：`{ "Id": 25, "Name": "赤兔马", "icon": "25" }`；
   加载器按 `.png → .jpg → .jpeg → .tga → .bmp` 顺序探测，换扩展名不用改数据；
3. **一张图可以被多件道具复用**：`icon` 指向"归属 Id"对应的文件即可
   （例如 `104 双股剑` 的 `icon` 是 `"35"`，与 `35 雌雄一对剑` 共用同一张双剑图）；
4. 也兼容子目录写法（如 `"icon": "4846-8/4846-8_5"`）。

## 加载方式

UI 侧用 **RawImage + Texture**（与头像同一套口径）：

```
icon 字段 → Assets/ItemIcon/{icon}
  ① Content 包：编辑器 Assets/Mods/Content/Assets/ItemIcon/…，运行时 Content.pkg
  ② ContentRootPath 下的裸文件：<ContentRootPath>/Content/Assets/ItemIcon/…
  ③ 都取不到 → Assets/empty.png 占位（不返回 null，UI 无需判空）
```
